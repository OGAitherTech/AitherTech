Is AitherTech connected to a real backend?

This GitHub Pages version is a front-end demo. Authentication, payments, device control, cloud storage and production APIs are not connected yet.

Where will device setup live?

The planned setup flow includes account creation, device registration, Wi-Fi connection, firmware check, pairing and completion.

What security features are planned?

HTTPS, device authentication, signed firmware, role-based access, two-factor authentication, audit logs, encrypted storage and secure-boot support.

Can developers use an API?

Yes. The architecture includes an HTTPS API plus WebSocket, OTA, storage and monitoring services.
