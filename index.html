Support

Help when you need it.

Build the support experience around knowledge, community, tickets, live chat, diagnostics, and system status.

How do I set up an Aither device?

Use the Device Setup flow: welcome → account → register device → Wi-Fi → firmware check → pair → finish.

How do OTA updates work?

Firmware is published to the firmware library, reviewed, and released to eligible devices.

Where are my backups?

Backups appear in Aither Cloud under Device Backups. Production storage is not connected in this demo.
