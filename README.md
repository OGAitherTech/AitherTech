# AitherTech

AitherTech is a GitHub Pages-ready front-end for the Aither technology platform, designed to present devices, cloud services, customer experiences, and developer tooling as one connected ecosystem.

## Current version

**Platform presentation upgrade — September 2026**

## Included
- Professional AitherTech landing page
- Aither Core, Aither Pulse, and accessories
- Smart home, remote access, OTA, security, voice control, and automations
- Pricing and plan comparison
- Interactive customer/cloud dashboard preview
- Buyer portal and developer portal preview areas
- Aither Cloud service architecture overview
- Device setup flow overview
- Support portal and FAQ
- Planned API/security architecture sections
- Main Aither subdomain map
- Responsive mobile and desktop layout
- Mobile navigation and keyboard-friendly interactions
- Search with `Ctrl/⌘ + K`
- Dark/light appearance preference
- Scroll progress and back-to-top controls
- Platform architecture section for Devices, Cloud, and Developers
- Custom 404 page
- Web app manifest
- No external framework or build step required

## Important
This repository currently contains a **front-end demo**. Authentication, payments, device control, cloud storage, firmware signing, OTA delivery, admin operations, API keys, and other production services are represented as UI/architecture placeholders and are not connected to a live backend.

The dashboard's example numbers and status cards are presentation mock data, not live service telemetry.

## GitHub Pages
The site can be published directly with GitHub Pages from the `main` branch. Custom domains/subdomains must be configured in GitHub Pages and DNS separately; a `CNAME` file alone does not make a domain live.
